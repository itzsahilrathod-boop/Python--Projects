# 🐍 Python Projects — 100 Days of Code

A collection of hands-on Python projects completed while working through **Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

This repository contains the projects from the first 15 sections/days of the course. The goal was not just to learn Python syntax, but to **build programs, solve problems, understand program flow, debug errors, and develop independent coding skills**.

> **Learning Python by building real programs, one project at a time.**

# 📚 Project Descriptions

## 01 — Band Name Generator

### Overview

A beginner-friendly interactive Python program that generates a potential band name from information entered by the user.

The program takes two pieces of user input and combines them to produce a personalized result.

### Concepts Practiced

- Variables
- Strings
- `input()`
- String concatenation
- Printing output
- Basic user interaction

### What I Learned

This project introduced the basic structure of a Python program and demonstrated how user input can be stored, processed, and displayed.

---

## 02 — Tip Calculator

### Overview

A program that calculates how much each person should pay when splitting a restaurant bill.

The user enters the bill amount, tip percentage, and number of people, and the program calculates the amount payable per person.

### Concepts Practiced

- Variables
- `input()`
- Type conversion
- Arithmetic operators
- Floating-point calculations
- Formatted output

### What I Learned

I practiced converting user input into numerical values and performing calculations programmatically.

## 03 — Treasure Island

### Overview

A text-based adventure game in which the player makes a series of choices while exploring a fictional treasure island.

Different decisions lead to different outcomes.

### Concepts Practiced

- `if`
- `elif`
- `else`
- Nested conditionals
- Comparison operators
- User input
- Program flow

### What I Learned

This project strengthened my understanding of conditional logic and showed how decisions can control the flow of a program.
